# UI Design Specification – แผนงาน

อ้างอิงแนวทาง D (สดใส เป็นมิตร) และ Layout 2 (ไทม์ไลน์เต็มจอ) ตาม canvas ที่เลือกไว้ ค่าสี ขนาด และ component อ้างจาก [design-system.md](design-system.md) รายละเอียดพฤติกรรมอ้างจาก [features.md](features.md)

## 1. โครงสร้างการนำทาง

```
/                         รายการโปรเจกต์
/p/:id/gantt              Gantt (หน้าหลักของโปรเจกต์)
/p/:id/calendar           ปฏิทิน
/resources                ทรัพยากร (กลาง ไม่ผูกโปรเจกต์)
/p/:id/gantt?task=t_01    เปิดแผงงานซ้อนบน Gantt (state อยู่ใน URL เพื่อแชร์ / กลับมาได้)
```

### Desktop shell (>= 1024px)

```
┌──────────────────────────────────────────────────────────────┐
│ HeaderBar (60px, พื้น primary, โค้ง 18)                        │
│  โลโก้ · [ระบบจองห้องประชุม ▾] · [Gantt][ปฏิทิน][ทรัพยากร] · avatar │
├──────────────────────────────────────────────────────────────┤
│ Toolbar ของหน้า (44px)                                        │
├──────────────────────────────────────────────────────────────┤
│ เนื้อหา (การ์ดสีขาวเต็มพื้นที่ที่เหลือ)                        │
└──────────────────────────────────────────────────────────────┘
```

- ไม่มี sidebar ซ้าย เพื่อให้ไทม์ไลน์กว้างที่สุด
- project switcher เป็น pill โปร่งบน header กดแล้วเปิดรายการโปรเจกต์แบบ popover พร้อมปุ่ม "ดูทั้งหมด" ไปหน้ารายการ
- แท็บ "ทรัพยากร" เป็นหน้ากลาง เมื่อเข้าจากโปรเจกต์จะกรองภาระงานของโปรเจกต์นั้นเป็นค่าเริ่มต้น

## 2. หน้าจอ Desktop

### 2.1 รายการโปรเจกต์ `/`

| ส่วน | รายละเอียด |
|---|---|
| Header | โลโก้ ชื่อระบบ ปุ่ม "ทรัพยากร" ขวา |
| Toolbar | ช่องค้นหา segment (ทั้งหมด / กำลังทำ / เสร็จแล้ว) ปุ่ม "โปรเจกต์ใหม่" (primary) |
| เนื้อหา | grid การ์ด 3 คอลัมน์ (`repeat(3, minmax(0,1fr))`) การ์ดสูง 140 |
| ProjectCard | ชื่อ (h3), ช่วงวัน "14 ก.ย. – 6 ต.ค. 2569", ProgressBar, แถวชิป: "งาน 7" (soft) "Critical 4" (critical) "เกินกำลัง 1" (warn ถ้ามี), เมนู ⋯ (ทำสำเนา ลบ) |

### 2.2 Gantt `/p/:id/gantt` (หน้าหลัก)

```
┌ Toolbar ────────────────────────────────────────────────────────┐
│ [≡ รายการงาน] [วัน|สัปดาห์|เดือน] ······ [Critical 4] [เสร็จ 6 ต.ค.] [+ เพิ่มงาน] │
├ การ์ด Gantt ────────────────────────────────────────────────────┤
│ ชื่องาน 220 │ หัวเวลา 2 แถว (สัปดาห์ / วัน)                        │
│ # ● ชื่อ    │ แถว 44px · แถบงาน pill 26px · ลูกศร · เส้นวันนี้        │
└──────────────────────────────────────────────────────────────────┘
```

องค์ประกอบ

- **คอลัมน์ชื่องาน** 220px: หมายเลข จุดสีสถานะ (critical / ทั่วไป / milestone) ชื่อ ตัดด้วย ellipsis; hover แสดง tooltip วันเริ่ม – สิ้นสุด และ float
- **หัวเวลา** 56px แถวบนชื่อสัปดาห์หรือเดือน แถวล่างเลขวัน; สุดสัปดาห์และวันหยุดสีจาง คอลัมน์แรเงา `--surface-2`
- **แถบงาน** pill สูง 26 ชื่อภายในเมื่อกว้าง >= 90px มิฉะนั้นแสดงเป็น tooltip; progress เป็นทับซ้อนทึบ 12% จากซ้าย
- **ลูกศร dependency** ออกจากปลายขวาของงานก่อนหน้า วิ่งแนวนอนครึ่งทาง หักลง แล้วเข้าซ้ายของงานถัดไป; ถ้างานถัดไปเริ่มก่อนปลายงานแรก (SS / lag ลบ) วิ่งอ้อมด้านล่างแถว
- **Float** เส้นประ 2px ต่อท้ายแถบตามระยะ Total Float
- **Milestone** เพชรเหลือง 16px กึ่งกลางแถว
- **เส้นวันนี้** 2px primary ตลอดความสูง
- **การ zoom** เปลี่ยนความกว้างคอลัมน์ (36 / 84 / 120px) โดยคงตำแหน่งวันที่อยู่กลางจอ
- **การเลือก** คลิกแถบหรือชื่อ = ring primary และเปิดแผงงานด้านขวา (320px ซ้อนทับการ์ด Gantt โดยไม่บีบไทม์ไลน์ มีเงา `--sh-card`)
- **ลาก** ระหว่างลากแสดงแถบโปร่ง 60% ที่ตำแหน่งใหม่ และงานที่ได้รับผลกระทบกระพริบเป็นสีจาง; tooltip บอกวันเริ่มใหม่และวันจบโปรเจกต์ใหม่
- **Drawer รายการงาน** เปิดจากซ้าย กว้าง 480 มีตารางเต็ม (ชื่อ ระยะ เริ่ม สิ้นสุด float ผู้ทำ) แก้ค่าในตารางได้ และลากเรียงแถว

สถานะ

| สถานะ | การแสดง |
|---|---|
| โหลด | skeleton แถว 6 แถวและแถบจาง |
| ไม่มีงาน | กลางการ์ด: "เริ่มด้วยการเพิ่มงานแรก" + ปุ่ม |
| มี cycle | toast error พร้อมชื่องานที่วน dependency ไม่ถูกบันทึก |
| แก้ไขไม่สำเร็จ | toast error และ rollback ค่าที่แสดง |

### 2.3 แผงงาน (TaskPanel)

กว้าง 320 ซ้อนขวาในการ์ด Gantt / ปฏิทิน เลื่อนภายในได้ ปุ่มบันทึกติดล่างเสมอ

ลำดับส่วนจากบนลงล่าง

1. หัว: "งาน #2" (caption) ชื่อ (h2 แก้ในที่) ปุ่มปิด
2. ชิป "อยู่บน Critical path" (แสดงเมื่อ float = 0) หรือ "Float 2 วัน" (soft)
3. แถว 2 ช่อง: ระยะเวลา (NumberInput วัน) · ความคืบหน้า (NumberInput %)
4. แถว 2 ช่อง: เริ่ม · สิ้นสุด (readonly มี tooltip "คำนวณจาก dependency")
5. Toggle: Milestone · Constraint "เริ่มไม่ก่อน" + DateInput เมื่อเปิด
6. งานก่อนหน้า: DependencyRow ต่อรายการ (ชื่อ, Pill ประเภท กดเปลี่ยน FS / SS / FF / SF, Pill lag กดแก้, ปุ่มลบ) + ปุ่มเส้นประ "เพิ่มงานก่อนหน้า" เปิด popover ค้นหางาน
7. งานถัดไป: รายการอ่านอย่างเดียว
8. ผู้รับผิดชอบ: แถว avatar ชื่อ Pill units ปุ่มลบ; ถ้าเกินกำลังแสดงกล่อง warn ใต้แถว "สุดา เกิน 150% วันที่ 21 – 22 ก.ย."
9. CpmBox: ES EF LS LF (grid 4 ช่อง) และบรรทัด Total float
10. ปุ่ม: บันทึก (primary เต็มกว้าง) · ลบ (danger-ghost)

การบันทึก: แก้แล้วบันทึกทันที (autosave debounce 500ms) ปุ่ม "บันทึก" มีไว้สำหรับกดปิดแผงและยืนยัน; ถ้าค่าผิดพลาด (duration < 0, cycle) ช่องเป็น error และไม่ส่ง

### 2.4 ปฏิทิน `/p/:id/calendar`

Toolbar: ปุ่ม ‹ › และ "วันนี้", ชื่อช่วง "กันยายน 2569", segment (เดือน / สัปดาห์), ตัวกรองทรัพยากร (ชิป avatar หลายตัว กดสลับ)

**มุมมองเดือน**: grid 7 คอลัมน์ ช่องสูงขั้นต่ำ 112px ชิปงานสูง 22 สีตามทรัพยากรหลัก ทอดข้ามวันเป็นแถบต่อเนื่อง สูงสุด 3 ชิปต่อช่องแล้ว "+2" ; วันที่มีทรัพยากรเกินกำลังแสดง OverloadBadge มุมขวาบนของช่อง

**มุมมองสัปดาห์ตามทรัพยากร**: แถวละทรัพยากร (avatar ชื่อ ภาระรวมสัปดาห์) คอลัมน์ละวัน ช่องมีชิปงาน ช่องที่เกินกำลังพื้น `--critical-bg` และตัวเลข % ; แถวสุดท้าย "ยังไม่มอบหมาย"

คลิกชิป = เปิดแผงงานเดียวกับ Gantt

### 2.5 ทรัพยากร `/resources`

Toolbar: ช่องค้นหา segment (ทั้งหมด / คน / เครื่องมือ) เลือกช่วงวัน ปุ่ม "เพิ่มทรัพยากร"

เนื้อหาแบ่ง 2 ส่วนแนวตั้ง

1. **การ์ดเตือน** (แสดงเมื่อมี): รายการเกินกำลัง แต่ละแถว avatar ชื่อ วันที่ % งานที่ชน ปุ่ม "ไปที่งาน"
2. **ตารางทรัพยากร**: คอลัมน์ ชื่อ (avatar สี) ประเภท capacity/วัน วันหยุด งานที่ได้รับ ภาระสัปดาห์นี้ (WorkloadBar) ความร้อน 14 วัน (WorkloadHeat) เมนู ⋯
   คลิกแถวเปิดแผงขวา: แก้ชื่อ ประเภท สี capacity รายการวันหยุด และรายการงานที่ได้รับแยกตามโปรเจกต์

### 2.6 ตั้งค่าโปรเจกต์ `/p/:id/settings`

เปิดจากเมนู ⋯ ข้าง project switcher หรือจากปุ่ม "ตั้งค่า" ท้ายชิปสรุปใน toolbar เป็นหน้าเต็มบน desktop (การ์ดกว้าง 760 กลางจอ) และหน้าเต็มบนมือถือ

หลักการของหน้านี้: **ทุกกติกาอธิบายเป็นภาษาคนก่อน ตามด้วยตัวอย่างสดจากโปรเจกต์นี้ แล้วค่อยบอกชื่อหลักที่อ้างอิงเป็นตัวจาง** ผู้ใช้ไม่ต้องรู้จัก CCPM หรือ PMBOK มาก่อนก็เลือกได้

โครงหน้า (ลำดับจากบนลงล่าง)

1. **ทั่วไป** ชื่อ วันเริ่ม
2. **วันทำงาน** ปุ่มวัน จ – อา แบบ toggle และรายการวันหยุดพร้อมปุ่มเพิ่ม (SET-8)
3. **สำรองเวลา** การ์ดเลือก 3 ใบเรียงแนวนอน (มือถือเรียงแนวตั้ง) ใบที่เลือกมีขอบ primary 2px และเครื่องหมายถูก แต่ละใบ:
   - ชื่อวิธี (h3) + ป้าย "แนะนำ" บนใบ ccpm
   - ประโยคอธิบาย 1 บรรทัด (ข้อความตาม features.md 3.13)
   - "เหมาะเมื่อ …" ตัวอักษร text-2
   - กล่องตัวอย่างสดพื้น `--surface-3`: "สายงานหลัก 17 วัน → เผื่อ 9 วัน → สัญญาส่ง 19 ต.ค." อัปเดตทันทีเมื่อเปลี่ยนตัวเลือกย่อย
   - ชื่อหลักอ้างอิงตัวจาง text-4 เช่น "Critical Chain (Goldratt)"
   - ตัวเลือกย่อยเฉพาะใบที่เลือก: ccpm → slider สัดส่วน 30 – 50% (SET-9); percent → segment ต่ำ / กลาง / สูง; pert → segment 84% / 98%
   - บรรทัดล่างสุดของส่วนนี้: management reserve % พร้อมคำอธิบาย 1 บรรทัด
4. **กติกาการคำนวณ** รายการการ์ดแนวตั้ง 1 ใบต่อกติกา (SET-1 ถึง SET-7, SET-10) แต่ละใบ: ชื่อกติกา, segment หรือ select ตัวเลือก, คำอธิบายของตัวเลือกที่เลือกอยู่ 1 ประโยค (เปลี่ยนตามที่เลือก), ตัวอย่างสดถ้ามี (เช่น SET-1 "ตอนนี้จะมีงาน critical 4 งาน" เปลี่ยนเป็น 6 เมื่อตั้ง ≤ 2 วัน), หลักอ้างอิงตัวจาง
   ใบที่ยังใช้ไม่ได้ (เช่น SET-3 แบบ baseline ก่อนมี baseline) แสดงจางพร้อมข้อความ "ใช้ได้เมื่อบันทึก baseline แล้ว"
5. **โซนอันตราย** ทำสำเนา ลบโปรเจกต์

พฤติกรรม

- ทุกการเปลี่ยนบันทึกทันทีและคำนวณตารางใหม่ toast "ปรับกติกาแล้ว · เลิกทำ" อยู่ 5 วินาที
- เมื่อเปลี่ยนวิธีสำรองเวลาจาก percent เป็น ccpm ครั้งแรก แสดง dialog 1 ครั้ง: "วิธีนี้ต้องการเวลาที่กรอกแบบไม่เผื่อ งานที่มีอยู่ 7 งานกรอกไว้แบบไหน" ปุ่ม "กรอกแบบไม่เผื่ออยู่แล้ว" / "มีเผื่ออยู่ ช่วยลดให้ 20%" (ระบบปรับ duration ทุกงานลง 20% ปัดขึ้น พร้อม undo ได้)
- ไอคอน ⓘ ข้างชื่อกติกาเปิด popover อธิบายยาวขึ้น 3 – 4 บรรทัดพร้อมตัวอย่างเปรียบเทียบ 2 ตัวเลือก

### 2.7 จุดที่อธิบายซ้ำนอกหน้าตั้งค่า

| จุด | ข้อความ |
|---|---|
| ช่องระยะเวลาในแผงงาน (โหมด ccpm) | placeholder "ถ้าราบรื่น กี่วัน" tooltip "ไม่ต้องเผื่อ ระบบเผื่อรวมไว้ท้ายโครงการแล้ว" |
| ช่องระยะเวลา (โหมด percent) | placeholder "กี่วัน" ไม่มี tooltip |
| ช่องระยะเวลา (โหมด pert) | 3 ช่อง "เร็วสุด / ปกติ / ช้าสุด" และแสดงค่าที่คำนวณได้ข้างล่าง |
| แถบ buffer ใน Gantt | tooltip สถานะการใช้ buffer เทียบความคืบหน้า และประโยคสรุปสีตามโซน |
| ชิปวันจบใน toolbar | "เสร็จตามแผน 6 ต.ค. · สัญญาส่ง 19 ต.ค." hover อธิบาย "สัญญาส่ง = เสร็จตามแผน + เวลาเผื่อ 9 วัน" |
| ป้าย critical ในตาราง (SET-1 > 0) | "Critical" กับ "ใกล้ critical (เลื่อนได้ 2 วัน)" ใช้สีต่างกัน: ชมพูเข้ม กับ ชมพูอ่อนขอบชมพู |

## 3. Component ร่วมที่ต้องสร้างก่อน

ลำดับที่แนะนำเพราะหน้าอื่นพึ่งพา

1. tokens.css, Button, IconButton, Chip, Pill, Avatar, Input family, Segment, Card
2. HeaderBar, BottomNav, Toolbar layout
3. GanttTimeline + TaskBar + DependencyArrow (หัวใจของระบบ)
4. TaskPanel + DependencyRow + CpmBox
5. Drawer, BottomSheet, Dialog, Toast
6. Calendar components, Workload components, ProjectCard

## 4. Tablet (768 – 1023px)

- HeaderBar คงเดิม แท็บย่อเหลือไอคอน + ข้อความสั้น
- Gantt ซ่อนคอลัมน์ชื่องานเป็นค่าเริ่มต้น เปิดได้จากปุ่ม "≡" กว้าง 160
- TaskPanel เป็น Drawer ขวา 360 ทับเนื้อหา มีฉากหลังมืด 30%
- ปฏิทินเดือนช่องสูง 96 ชิปสูงสุด 2 ต่อช่อง

## 5. มือถือ (< 768px)

หลักคิด: มือถือเน้น **ดูและปรับเล็กน้อย** ไม่ใช่วางแผนใหม่ทั้งหมด งานหนักอย่างลาก dependency ทำบน desktop

### 5.1 Shell

```
┌──────────────────────────────┐
│ Header 52: โลโก้ · ชื่อโปรเจกต์ ▾ · ⋯ │
│ Toolbar: [สัปดาห์|เดือน] [Critical 4] │
│                              │
│ เนื้อหา (การ์ดเต็มกว้าง)       │
│                              │
├──────────────────────────────┤
│ BottomNav 64: Gantt · (+) · ปฏิทิน · ทรัพยากร │
└──────────────────────────────┘
```

- BottomNav สูง 64 + safe-area ปุ่มกลาง "+" เป็นวงกลม 56 พื้น ink ลอยขึ้น 12px สำหรับเพิ่มงาน
- ไม่มี zoom ระดับ "วัน" บนมือถือ (เริ่มที่สัปดาห์ 28px/วัน)
- แตะค้างชื่อโปรเจกต์เพื่อสลับโปรเจกต์ (bottom sheet รายการ)

### 5.2 Gantt มือถือ

- คอลัมน์ชื่องาน 120px ตรึงซ้าย ชื่อตัดสองบรรทัดสูงสุด
- ไทม์ไลน์เลื่อนแนวนอนด้วยนิ้ว ปุ่ม "วันนี้" ลอยมุมขวาล่างเหนือ BottomNav
- แถบงานสูง 24 ไม่มีชื่อในแถบ แตะเปิด bottom sheet
- ไม่มีการลากแถบบนมือถือ (ป้องกันชนกับการเลื่อน) ปรับวันผ่าน sheet แทน
- ลูกศร dependency แสดงเฉพาะเมื่อเปิดสวิตช์ "แสดงเส้นเชื่อม" ในเมนู ⋯ (ค่าเริ่มต้นปิด เพื่อลดความรก)
- ปุ่ม "รายการงาน" ย้ายไปในเมนู ⋯ เปิดเป็นหน้าเต็ม

### 5.3 แผงงานเป็น Bottom sheet

- เปิดครึ่งจอ (ส่วนหัว ชิป ระยะเวลา progress เริ่ม – สิ้นสุด) ลากขึ้นเต็มจอเห็นส่วนที่เหลือ
- ที่จับลาก 36×4 บนสุด โค้งบน 24 เงา `--sh-float`
- ช่องกรอกสูง 44 (จาก 38) ปุ่มบันทึกติดล่างเหนือ safe-area
- Pill ประเภท dependency แตะแล้วเปิด action sheet 4 ตัวเลือกพร้อมคำอธิบายสั้น

### 5.4 ปฏิทินมือถือ

- แสดงเฉพาะมุมมองสัปดาห์ตามทรัพยากร: เลือกทรัพยากรด้วยแถวชิป avatar เลื่อนแนวนอนด้านบน แล้วแสดงรายการวัน (จ – อา) แนวตั้ง แต่ละวันมีชิปงานของคนนั้น วันเกินกำลังพื้น `--critical-bg` พร้อม %
- ปัดซ้ายขวาเปลี่ยนสัปดาห์

### 5.5 ทรัพยากรมือถือ

- รายการการ์ดต่อคน: avatar ชื่อ ประเภท WorkloadBar สัปดาห์นี้ และตรา "เกิน 150%" ถ้ามี
- แตะเปิด bottom sheet แก้ไข

### 5.6 รายการโปรเจกต์มือถือ

- การ์ดเรียง 1 คอลัมน์ ปุ่มสร้างเป็น FAB

ภาพร่างมือถือ 3 หน้า (Gantt, bottom sheet งาน, ปฏิทินตามทรัพยากร) อยู่ในหน้า "มือถือ" ของ canvas
